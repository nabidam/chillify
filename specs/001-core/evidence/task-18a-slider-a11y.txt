Task 18a — scoped fix: Slider thumb accessible name (serious axe finding)
Evidence captured live at HEAD e5eb2e8 (fix commit not yet made when captured;
committed immediately after this file, SHA recorded in TASKS.md).

======================================================================
Defect (recorded in ARCHITECTURE's 2026-07-26 "Task 18 findings" entry and
specs/001-core/evidence/task-18.txt lines ~130-149): Radix places
role="slider" on SliderPrimitive.Thumb, not on SliderPrimitive.Root. The
Shadcn wrapper (frontend/src/components/ui/slider.tsx) forwarded a call
site's aria-label only onto Root via {...props}, so the Thumb — the element
axe inspects for role=slider — never received an accessible name. Reported
by axe as aria-input-field-name (serious) on every screen, since
PersistentPlayer (frontend/src/features/player/PersistentPlayer.tsx) is
always mounted.
======================================================================

======================================================================
1. Fix applied
======================================================================

- frontend/src/components/ui/slider.tsx: added an optional
  `thumbLabels?: readonly string[]` prop; each rendered
  `SliderPrimitive.Thumb` now gets `aria-label={thumbLabels?.[index]}`
  (typed `string | undefined` under noUncheckedIndexedAccess — the correct
  type for an optional aria-label).
- frontend/src/features/player/PersistentPlayer.tsx: the Seek slider now
  passes `thumbLabels={["Seek"]}` and the Volume slider
  `thumbLabels={["Volume"]}`, alongside the pre-existing `aria-label` on
  each call site (left in place — it still lands on Root, which
  firefox-smoke.spec.ts locates by: `getByLabel("Seek").getByRole("slider")`).
- frontend/tests/component/slider-accessibility.test.tsx: new Vitest
  component test pinning the fix directly against the Slider wrapper
  (3/3 passing, shown below).
- ARCHITECTURE.md: new 2026-07-26 decision-log entry recording the
  hand-edit of a generated Shadcn primitive and the user's approval.
